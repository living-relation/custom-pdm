# custom-pdm

Personal 12 V power distribution module (PDM) for car accessories: 24 outputs (16 x 8 A, 6 x 15 A, 2 x 30 A), 16 universal inputs, controlled over CAN by a Link G4X ECU.

Based on [corygrant/dingoPDM](https://github.com/corygrant/dingoPDM) (MIT). Personal project, not for sale.

Progress and open items: see [STATE.md](STATE.md).
