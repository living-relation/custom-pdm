# custom-pdm

Personal 12 V power distribution module (PDM) for car accessories: 24 outputs (16 x 7.5 A, 4 x 15 A, 4 x about 31 A on studs; one 7.5 A output, A2 OUT2, powers the internal fans, so 23 are for the car) and about 25 on/off inputs over three boards, controlled over CAN by a Link G4X ECU.

Based on [corygrant/dingoPDM](https://github.com/corygrant/dingoPDM) (MIT). Personal project, not for sale.

Progress and open items: see [STATE.md](STATE.md).
