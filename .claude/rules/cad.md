# CAD (enclosure, models, drawings)

Enforcer: the enclosure build checks (overlaps, clearances incl. same-net screw heads, lugcheck, BOM / part-file check, CNC check); `workstation\app-lock\app-lock.ps1` (harness.design lock only); none yet for the rest (Fusion: the coordinator's job plan).

- All CAD (models and engineering drawings) follows the Handbuilt-CAD repo rules, whether built with Fusion or handbuilt-CAD tools (claude.ai project instructions, 2026-11-17).
- Models and drawings are saved in the OneDrive models folder (`C:\Users\danie\.personal OneDrive\OneDrive\Desktop\models\`), as versioned, hash-verified release folders (publish-to-models). Never edit assembly drawings directly: models first, drawings generated from the models, parts lists and BOM generated from those.
- Every part is its own external model file inserted into the assembly (Fusion linked components, one design per part; one STEP per part); no part exists only inside an assembly. Every part carries its correct part number and description (bought: maker part number; made: project part number + revision + material) so the BOM populates; the build check fails on a missing one (Dan, 2026-11-16).
- Purchased parts use the maker's real CAD (connectors, bulkheads, fans, terminals), not placeholder shapes. Downloading maker drawings / CAD is always OK; TE ECAD terms are accepted.
- Clearance: insulated wire may touch plastic; only bare metal (lugs, screws, risers) needs real clearance, same-net bare metal included (machining). CNC curves are smooth continuous sweeps, not facets.
- Claude owns the enclosure design (Dan, 2026-11-16); board STEPs are exported from our own KiCad files.
- Fusion on DansPC: only one agent drives Fusion at a time, by the coordinator's job plan; no lock script covers Fusion any more (workstation #113, 2026-11-22: `fusion-lock.ps1` became `C:\projects\active\workstation\workstation\app-lock\app-lock.ps1`, harness.design only, and `agents\projects-AGENTS.md` moved to `C:\projects\active\workstation\instructions\projects-AGENTS.md`). The harness.design desktop app: hold its lock per that file's section 5b (`app-lock.ps1 acquire / checkin / release -Name harness-design`: check in every 10 min, release when done).
- One solid = one part; anything installed in a separate step is its own part; several pieces = an assembly / subassembly of linked parts, never one fused body (Never do: the v2c sink was released with the feet fused in, 2026-11-20). The build check fails a made part with more than one solid and a bought part without its maker model (Dan, 2026-11-20).
- Every external part and subassembly sits in a `Parts` folder at the assembly root (Fusion and the STEP release) and opens from the top assembly. Screws, nuts, washers and set screws go in with Dan's SR Fasteners Fusion add-in and live inside the assembly / subassembly as separate bodies (the only exception); a fastener SR Fasteners lacks is an external part (Dan, 2026-11-20).
- Every new or updated model also gets a user STEP copy with the same tree as the source; the Fusion-vs-STEP tree check must pass. One source-of-truth assembly built from the newest part models: no per-rev duplicate designs or folders (Dan, 2026-11-20).
- Models folder: `<subject>-rev<current>\rev<X>\`; keep only the newest and the previous rev of anything and delete the oldest when a new one is filed (Dan, 2026-11-20; overrides handbuilt-cad's 'latest + 2'). Rule changes for handbuilt-cad / workstation are not made from this repo: hand Dan a copy block.
- Wires are modelled as real round 3D wires along their path (Dan's ST185 fuse box models are the example), not placeholder blocks (Dan, 2026-11-21).
- Check a model against these rules before releasing it and before answering Dan about it (Never do: explained a screenshot before checking the model, 2026-11-20). Fusion is driven through Fusion's built-in MCP; no lock script locks Fusion (see the Fusion line above).
- Wire models show the loom's lanes, fit and lengths: fail on a wire through a part, outside the box, a tight bend or a gross pile-up; do not chase a model where no two wires touch (Never do: two jobs spent on a no-touch router, 2026-11-21).
